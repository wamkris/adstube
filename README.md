# AdsTube

A HackerTube-style curated library of **Amazon Ads** videos, built so you can learn from experts without YouTube's clickbait thumbnails or generic "make money on Amazon" feed.

Open `index.html` through a local server:

```bash
cd /workspace/adstube
python3 -m http.server 8765
```

Then visit http://127.0.0.1:8765/

Likes, history, Watch later and **My notes** (Idea / Test / Result) stay in this browser. Mid-frame thumbnails (`hq2.jpg`) are on by default; turn them off in Settings.

AdsTube is not affiliated with YouTube, Google, or Amazon.
